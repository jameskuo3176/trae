上传 QoR CSV 文件（支持多文件批量导入）
Makefile 自动上传时建议传入当前 run 目录的 $(PWD)，便于按目录区分多 corner / 多子目录 run
勾选后本次上传的所有记录将自动对外可见，无需再去「记录管理」手动发布
支持的 CSV 字段说明:
解析器自动识别列名（不区分大小写，忽略空格/下划线/连字符差异）。常见列名:
tag, full_dir, comment, reg_count, comb_count, macro_count, total_count, reg_area, comb_area, macro_area, stdcell_area, total_area, no_clock, {CLOCK}_period, {CLOCK}_wns, {CLOCK}_tns, {CLOCK}_path
其中 {CLOCK} 为时钟名（如 SRAMCLK），可同时存在多个时钟列。
tag 会作为图表上的标签。
多时钟数据中，最负 WNS 会作为整体 WNS，所有 TNS 之和作为整体 TNS。
功耗合并: 选择"功耗数据"时，系统按 模块+版本 匹配已有记录，仅更新功耗字段，不会覆盖 QoR 数据。
容错能力: 跳过空行、处理列数不一致、支持科学计数法/千分位/带单位数值、识别多种空值表示(-, N/A, NULL 等)。
批量上传历史数据: 勾选"整目录上传"选择整个项目目录，模块名来源选"从文件名提取"或"从父目录名提取"。 例如目录结构 proj_dir/module_a/module_a_qor.csv，选"从父目录名提取"会自动把 module_a 作为模块名，每个 CSV 的多行作为该模块的不同 run 版本（用 tag 列区分）。建议先用"预览校验"确认模块名提取正确。
补充 FlopCount 数据 (block_qor.csv)

通过 Fulldir 列匹配已有 QoR 记录，仅补充 FlopCount 和 FlopCount_incr 字段。 不新建记录，不覆盖已有 QoR 数据。

说明:
- CSV 需包含 Fulldir 列（匹配键，对应已有记录的 full_dir），以及 FlopCount / FlopCount_incr 列。
- Header 大小写不敏感，支持别名: Fulldir/full_dir/fuldir、FlopCount/flop_count/flops 等。
- 匹配规则: Fulldir 唯一匹配已有记录。命中多条则跳过(冲突)，命中 0 条则跳过(未匹配)。
- 仅 FlopCount 或 FlopCount_incr 至少有一个非空才会更新。
- 幂等: 重复上传相同数据不会重复计数。
